# Лабораторная 1 по дисциплине "Технологии программирования"
# Лабораторная работа №1 — TPLab1Sadykov-rating

## 📘 Постановка задачи

Цель лабораторной работы — разработать программный проект для обработки данных о студентах, вычисления их рейтингов и анализа задолженностей.  
Проект должен быть структурирован, покрыт модульными тестами и интегрирован с системой непрерывной интеграции GitHub Actions.

Индивидуальное задание включает:

1. Выбор типа лицензии и добавление файла LICENSE.
2. Добавление файла .gitignore.
3. Реализацию нового класса-наследника `DataReader` для обработки данных индивидуального формата и покрытие его тестами.
4. Реализацию класса для вычисления характеристик студентов (согласно варианту) и покрытие его тестами.
5. Составление UML‑диаграммы классов итогового проекта.
6. Формирование выводов по работе.

---

## 📦 Краткое описание проекта

Проект реализует:

- чтение данных о студентах из текстовых и JSON‑файлов;
- вычисление рейтинга студентов на основе их оценок;
- определение количества студентов‑должников;
- модульное тестирование всех ключевых компонентов;
- автоматическую проверку стиля кода и тестов через GitHub Actions;
- работу с Git‑ветками и объединение изменений согласно методичке.
